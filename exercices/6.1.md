# Exercice 6.1 : *MongoDB et Mongoose*

## Warning

- Supprimez l'id numérique des informations à stocker dans la base de données car une nouvelle clé *_id* contenant la clé est générée automatiquement par MongoDB afin d'identifier une entité de manière unique.

---

## Énoncé

1. Reprenez [l'Exercice 5.3 sur la ligue des champions](./5.3.md).

2. Créez les schémas *Mongoose* pour les entités suivantes **sans la clé *id*** pour laisser à MongoDB générer automatiquement la clé *_id* :
- *team* pour l'équipe
- *game* pour le match
- *player* pour le joueur
3. Implémentez les actions ***CRUD (create, read, update and delete)*** suivantes pour stocker les informations dans la base de données MongoDB : 
- L'ajout d'une nouvelle équipe dans la collection teams
- La modification d'une équipe
- La supprission d'une équipe
- La récupération d'une équipe à partir de son nom

---

## Bonus

1. Effectuez les opérations *CRUD* sur le schéma *game*
2. Effectuez les opérations *CRUD* sur le schéma *player*
