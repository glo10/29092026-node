# Exercice 5.3 : API REST

## Aides

- Pour les requêtes POST et PUT ulisez l'un des outils suivants :
  - Postman (nécessite un compte)
  - L'extension ThunderClient (pas besoin de compte pour un usage limité largement suffisant pour cet exercice)
  - Curl avec les commandes suivantes
  ```bash
  # POST
  curl -X POST -H "Content-Type: application/json" -d '{"name": "RC Lens", "country": "France"}' http://localhost:5300/teams
  # PUT
  curl -X PUT --json '{"home": 1, "away": 2, "score": "0-1", "date": "2026-09-09"}' http://localhost:5300/games/1
  ```

## Énoncé

1. Créez un nouveau projet avec Express **sans** ***Express CLI*** (avec *npm install express*)

2. Créez une ***API REST*** pour la **Ligue des champions 2026-2027 phase finale** pour répondre aux besoins ci-dessous, vous pouvez vous appuyer sur les informations du site [***EuroSport***](https://www.eurosport.fr/football/ligue-des-champions/calendrier-resultats.shtml) sur la compétition. Votre application écoute sur le port ***5300***

**PS : il n'est pas demandé de restituer tous les clubs et matchs, un petit échantillon suffira amplement** 


| Méthode HTTP | Endpoint   | Ressources             |
| -------- | -------------- | ---------------------- |
| `GET`    | `/teams`       | Liste des équipes (clubs) |
| `GET`    | `/teams/:id`   | Un seul club |
| `POST`   | `/teams` | Ajouter une équipe       |
| `GET`    | `/games` | Liste de tous les matchs |
| `POST`   | `/games` | Ajouter un match       |
| `PUT`    | `/games/:id` | Mettre à jour un match |

- Pour la route ***POST /teams*** : il faut stocker les utilisateurs dans un fichier JSON.
- Pour simplifier : à chaque ajout d'une équipe, récupérez le contenu acutel du fichier JSON, puis ajoutez la nouvelle équipe dans votre tableau enfin insérez en écrasant le contenu initial.
- Pour parser le JSON (transformer le contenu textuel de votre fichier en objet JS), utilisez la fonction ***JSON.parse(data)*** avec *data* le contenu du fichier JSON.


### Structure des données de votre API

```json
{
  "teams": [
    { "id": 1, "name": "Naples", "country": "Italy" },
    { "id": 2, "name": "Arsenal", "country": "UK" },
    { "id": 3, "name": "Paris Saint-Germain", "country": "France" },
    { "id": 4, "name": "ŠK Slovan Bratislava", "country": "Slovakia" }
  ],
  "games": [
    { "id": 1, "home": 1, "away": 2, "score": "0-1", "date": "2026-09-09" },
    { "id": 2, "home": 3, "away": 4, "score": "6-1", "date": "2026-09-09" }
  ]
}
```

Ici les propriétés *home* et *away* stockent les identifiants des équipes par exemple pour le match avec l'*id* 1, c'est le *Naples* qui a joué à domicile avec une défaite 0-1 face à la *Arsenal* (équipe à l'extérieur).
